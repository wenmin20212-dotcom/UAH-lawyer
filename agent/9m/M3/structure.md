# M3 knowledge support structure

Profession: 律师
Revision: 2
Status: draft

## M3C.1 — 法律职业与执业边界知识

Parent:

收录律师职业角色、法律服务边界、人工责任、保密、利益冲突、执业伦理和对外成果责任等基础知识，用于约束 Agent 只能作为律师工作辅助系统而非独立法律服务主体。

Capabilities: M2.1, M2.3, M2.4, M2.5

Includes:
- 律师职业角色与法律服务关系的基本概念
- 律师与客户、律师助理、团队成员之间的职责边界
- 保密义务、利益冲突、委托范围、对外沟通责任的通用知识
- 人工复核、律师最终判断和对外成果批准的责任结构
- 法律工作中事实、陈述、依据、推论和意见的区分原则

Excludes:
- 具体案件事实
- 某一事项的实际委托文件内容
- 具体律所的内部审批流程
- 当前任务执行状态
- 未经来源确认的具体执业规则条文

Knowledge needs:
- 律师执业行为、保密义务、利益冲突和委托关系的权威规则
- 律师辅助型 Agent 的责任边界知识说明
- 法律工作成果中事实、法律依据、分析意见和结论的标注规范

## M3C.2 — 事项识别与客户需求分析知识

Parent:

收录将客户初始描述转化为法律事项定义所需的知识，包括事项类型识别、需求澄清、服务范围界定、目标与约束识别、缺失信息判断和待确认问题组织。

Capabilities: M2.1

Includes:
- 客户需求访谈和需求澄清的法律服务知识
- 法律事项目标、范围、背景、主体、时间、地域和司法辖区的识别要素
- 非诉专项、常年法律顾问、民商事诉讼等场景下的需求差异
- 已知信息、用户陈述、推测和待核实事项的区分方法
- 缺失材料和待确认问题的识别规则

Excludes:
- 具体客户的商业秘密
- 实际案件的客户陈述原文
- 当前事项的任务清单或执行进度
- 最终法律判断
- 律师是否正式接受委托的决定

Knowledge needs:
- 公司商事、合同事务、民商事诉讼中常见客户需求类型
- 事项范围、事项目标、司法辖区、适用法律和服务成果类型的识别框架
- 法律服务需求访谈中的常见追问维度和风险提示维度
- 缺失材料清单的通用分类知识

## M3C.3 — 事实、材料与证据组织知识

Parent:

收录法律事项中材料接收、事实梳理、主体关系、时间线、证据属性和可追溯关系所需的通用知识，用于支持律师理解事项背景和后续法律分析。

Capabilities: M2.2, M2.3, M2.4, M2.5

Includes:
- 事实与证据的基本区分
- 主体关系、交易关系、行为关系和时间线的组织方法
- 材料来源、证明对象、证明力、真实性和完整性的常见审查维度
- 民商事诉讼和合同事务中的证据整理知识
- 材料、事实、问题、法律依据和输出之间的追溯关系

Excludes:
- 当前案件的实际证据内容
- 证据原件、扫描件或客户提交材料本身
- 对具体证据真实性的最终认定
- 诉讼中由法官作出的事实认定
- 正在执行的证据整理步骤

Knowledge needs:
- 民商事事项中常见材料类型和证据类型
- 事实时间线、主体关系图、材料索引和证明对象之间的映射知识
- 证据真实性、关联性、合法性和证明目的的通用审查框架
- 非诉材料整理与诉讼证据整理的知识边界

## M3C.4 — 法律依据检索与规范体系知识

Parent:

收录法律法规、司法解释、监管规则、案例、裁判观点和其他法律依据的检索、层级、效力、适用范围、时效性和引用方法等知识。

Capabilities: M2.3, M2.4, M2.5

Includes:
- 法律渊源、规范层级和法律效力的基础知识
- 法规、司法解释、指导性案例、类案和裁判文书的区分
- 法律依据检索、筛选、核验和引用的通用方法
- 适用法律、司法辖区、时间效力和事项类型之间的关系
- 法律依据状态不明时的提示与核实要求

Excludes:
- 未注明来源和日期的具体法条摘录
- 未经核实的法规有效性结论
- 当前案件的法律检索结果清单
- 把模型记忆当作已核实法律来源
- 对具体事项的最终适用法律结论

Knowledge needs:
- 目标司法辖区法律渊源和规范效力层级知识
- 法律法规、司法解释、案例和裁判观点的检索与引用规范
- 法律依据有效性、适用范围和更新时间的核验要求
- 类案检索结果在律师分析中的辅助地位

## M3C.5 — 公司商事法律知识

Parent:

收录公司设立、治理、股权、投融资、重大交易、合规经营和商事主体关系等公司商事领域知识，用于支撑面向企业客户的非诉与争议事项分析。

Capabilities: M2.1, M2.3, M2.4, M2.5

Includes:
- 公司主体、股东、董事、高级管理人员和实际控制人的基本法律关系
- 公司治理、股权结构、出资、转让、决议和信息披露相关知识
- 企业日常经营中的商事交易和合规风险知识
- 中小企业、大型企业和上市公司的差异化法律需求
- 公司商事争议的常见问题类型

Excludes:
- 具体企业的内部资料
- 某一公司的股权结构事实
- 未核实的具体法律条文
- 证券监管或上市公司事项的最终合规结论
- 当前客户的商业决策建议

Knowledge needs:
- 目标司法辖区公司法及相关商事规则的基础知识
- 企业客户常见公司商事法律问题类型
- 公司治理、股权、决议、交易和争议之间的概念结构
- 不同规模企业法律服务需求差异

## M3C.6 — 合同法律与合同审查知识

Parent:

收录合同成立、效力、履行、变更、解除、违约责任、条款结构、风险分配和合同审查方法等知识，用于支持合同事务和合同相关争议分析。

Capabilities: M2.3, M2.4, M2.5

Includes:
- 合同主体、标的、价款、履行、违约、解除、争议解决等核心条款知识
- 合同效力、合同解释和履行风险的基础知识
- 合同审查中的权利义务配置、风险分配和可执行性分析
- 常见商事合同类型及其条款关注点
- 合同审查意见和修改建议的组织方式

Excludes:
- 具体合同文本中的客户商业秘密
- 直接替代律师给出最终合同修改决定
- 未经核实的强制性法律要求
- 当前合同审查任务的实际修订痕迹
- 交易结果保证

Knowledge needs:
- 目标司法辖区合同法律基础规则
- 合同审查的条款分类、风险维度和意见表达框架
- 常见商事合同类型的审查要点
- 合同审查草稿与律师最终意见之间的边界

## M3C.7 — 民商事诉讼知识

Parent:

收录民事和商事诉讼中的程序、主体、请求权、争点、证据、诉讼策略、裁判逻辑和诉讼文书基础知识，用于支持诉讼事项的辅助分析和草稿准备。

Capabilities: M2.2, M2.3, M2.4, M2.5

Includes:
- 民商事诉讼程序阶段和基本诉讼结构
- 诉讼主体、诉讼请求、事实理由、抗辩和争点整理知识
- 举证责任、证据规则和证明标准相关知识
- 类案、裁判观点和诉讼风险分析知识
- 起诉状、答辩状、代理意见、证据目录等文书的结构知识

Excludes:
- 具体案件的诉讼策略最终决定
- 未经律师确认直接提交法院的诉讼文件
- 法官对具体案件的裁判结论
- 当前案件事实和证据材料本身
- 保证案件结果

Knowledge needs:
- 目标司法辖区民商事诉讼程序知识
- 诉讼请求、抗辩、争点和证据之间的结构关系
- 诉讼文书草稿的通用结构知识
- 类案检索和裁判观点分析的知识框架

## M3C.8 — 法律分析与论证方法知识

Parent:

收录将事实、问题、法律依据和推理过程组织成可审阅法律分析的通用方法，包括请求权基础、构成要件、风险评估、类比区分和结论限定。

Capabilities: M2.3, M2.4, M2.5

Includes:
- 法律问题识别和法律关系分析方法
- 事实与法律规范之间的匹配方法
- 构成要件分析、请求权基础分析和抗辩分析知识
- 风险等级、依据强弱、事实不确定性和结论限定的表达方法
- 法律论证中引用依据、说明推理和保留待核实事项的方式

Excludes:
- 对具体案件的最终法律结论
- 未经律师确认的对外法律意见
- 单纯文案润色技巧
- 当前任务的实际分析记录
- 把不确定推论表述为确定结论

Knowledge needs:
- 公司商事、合同、民商事诉讼中常用法律分析方法
- 事实不明、依据不明、法律适用不明时的结论限定知识
- 法律分析草稿中依据、推理和结论的表达规范
- 法律风险识别与风险等级描述的通用框架

## M3C.9 — 法律工作成果与客户汇报知识

Parent:

收录律师团队向内部或客户呈现工作成果所需的结构知识，包括研究摘要、合同审查意见、事项备忘录、客户汇报、待确认事项和审阅友好型草稿格式。

Capabilities: M2.5

Includes:
- 法律研究摘要、合同审查意见和客户汇报的常见结构
- 面向律师审阅的草稿表达要求
- 事项背景、核心问题、依据、分析、结论和待确认事项的呈现方式
- 对客户沟通中确定事项、不确定事项和需律师确认事项的标注方法
- 工作成果可追溯性的呈现知识

Excludes:
- 未经律师确认直接对外发送的文件
- 当前客户汇报的具体内容
- 律所特定模板的受限版本
- 对外承诺或结果保证
- 最终法律意见的批准行为

Knowledge needs:
- 律师审阅型草稿的通用结构和标注规范
- 客户汇报中常见信息层级、风险提示和待确认事项表达方式
- 法律研究摘要和合同审查意见的内容边界知识
- 内部工作稿、客户沟通稿和正式法律意见之间的区别

## M3C.10 — 企业客户行业与商业背景知识

Parent:

收录理解中小企业、大型企业和上市公司法律需求所需的基础商业知识，包括组织结构、经营活动、交易场景、合规环境和决策机制，但不收录具体客户的个别事实。

Capabilities: M2.1, M2.4, M2.5

Includes:
- 企业组织结构、部门职能和常见决策流程的通用知识
- 企业交易、采购、销售、融资、投资、用工和合规场景的基础知识
- 中小企业、大型企业、上市公司在法律需求上的一般差异
- 商业目标、法律风险和管理约束之间的关系
- 企业客户与律师团队协作中的常见信息需求

Excludes:
- 具体客户的经营数据
- 具体交易的商业秘密
- 行业监管的未经核实具体规则
- 商业决策替代建议
- 当前项目的客户内部沟通记录

Knowledge needs:
- 企业客户常见组织角色和材料来源
- 企业客户法律需求与经营场景之间的映射知识
- 不同类型企业法律服务协作方式差异
- 商业背景知识与具体客户事实之间的边界

## M3C.11 — 法律知识来源、更新与质量控制知识

Parent:

收录法律知识持续维护所需的来源记录、法域标注、日期标注、有效性核验、版本更新、引用质量和人工认可机制等知识治理方法。

Capabilities: M2.3, M2.4, M2.5

Includes:
- 法律知识来源、法域、日期、许可和适用范围的记录要求
- 法律规则更新、失效、修订和冲突时的处理知识
- 人工认可、结构检查和专业正确性验证之间的区别
- 法律知识条目的质量控制、引用和追踪方法
- 活跃知识、待认可知识和过期知识的区分原则

Excludes:
- 具体未核实法律条文
- 把结构检查视为法律正确性认证
- 当前案件事实或任务状态
- 实际工具配置
- 未经授权自动扩大知识适用范围

Knowledge needs:
- 法律知识条目的来源、法域、日期和适用范围记录规范
- 法律知识更新、废止和冲突处理的治理方法
- 结构化知识入库与律师专业核验之间的责任边界
- 法律依据引用质量控制的参考实践

## M3C.12 — 法律服务中的 AI 辅助安全与治理知识

Parent:

收录法律 Agent 在辅助律师工作时所需的安全、合规、隐私、保密、误导风险、幻觉风险、可追溯性和人工监督知识，用于保障辅助系统不越界、不伪造依据、不替代专业责任。

Capabilities: M2.1, M2.2, M2.3, M2.4, M2.5

Includes:
- 法律服务场景下 AI 输出不确定性和幻觉风险知识
- 客户材料、保密信息和个人信息处理的治理知识
- 人工监督、律师复核和对外发布控制的知识
- 输出可追溯、依据标注和不确定性提示的治理要求
- 法律 Agent 辅助角色与专业责任边界的安全知识

Excludes:
- 具体系统的权限配置
- 实际安全沙箱实现步骤
- 当前客户资料
- 将 AI 输出视为律师最终意见
- 未经律师确认的对外法律结论

Knowledge needs:
- 法律服务中 AI 辅助系统的风险类型
- 不确定性提示、来源标注和人工复核的安全治理知识
- 客户保密信息和个人信息处理的通用合规要求
- 法律 Agent 不得替代律师专业判断的治理原则
