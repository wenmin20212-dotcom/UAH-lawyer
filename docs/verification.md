# 0.1.0 发布验证范围

本版以既有律师脱模原型为输入，建立独立启动层及 Windows 安装程序。确认发布内容不含母机目录、运行数据、模型账号或案件原件；专业定义中的原开发电脑绝对路径已移除，项目身份改为 uah-lawyer。

验证分为两层：

- bootstrap 单元检查：安装版数据与程序分离、便携版数据就地保存、用户配置及实例身份保留、清除母机运行环境、窗口标题回调。
- 真实安装程序检查：隔离安装、真实桌面窗口加载、独立名称和版本、Node/npm/后端运行、桌面及开始菜单快捷方式目标/图标、覆盖安装保留配置和哨兵数据、卸载保留独立用户数据。

验证摘要作为 Release 的 installer-verification.json 附件发布。真实检查使用独立测试目录，不覆盖已有“律师助手”测试快捷方式；测试“律师助手 UAH”入口在卸载后移除。

验证没有配置模型账号、没有调用法律业务或测试实际法律输出。当前产品是加载职业设计定义的 prototype；五项能力的结构契约确认不能替代它们的程序实现。仅在本机 Windows x64 进行了安装运行检查，未实际测试另一台实体电脑。

完整重编译通用宿主不在此仓库范围内。这里使用固定宿主二进制依赖，重建专用启动和发布层；下载 URL 和 SHA256 见 runtime-reference.json。
